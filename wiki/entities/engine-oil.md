# 四行程引擎機油實體說明

> 機油是引擎運轉的血液，兼具潤滑、冷卻、清潔、防鏽與密封之關鍵功能。

## 1. 原廠認證與黏度推薦
- **API 認證**：SL 級或以上（常見 API SL / SM / SN / SP）。
- **JASO 規範**：
  - 速克達為乾式離合器，建議使用 **JASO MB**（超低摩擦阻力，兼顧油耗與拉轉順暢度），亦相容 **JASO MA / MA2**。
- **建議黏度（SAE Viscosity）**：
  - **10W-40**：全天候通勤與長途兼備，高溫油膜保護性佳。
  - **10W-30**：低溫流動性優，市區短途通勤省油、油門輕快。
  - **5W-40**：全合成高等級油品，抗衰退性好，適合激烈操駕。

## 2. 容量與注入量規範（手冊 vs 實務）
- **引擎分解總容量**：1,050 c.c.
- **手冊更換容量**：1,000 c.c.
- **社群實務最佳推薦**：
  - 一般由側邊 12mm 洩油螺栓重力洩出，排出量約 **800 ~ 850 c.c.**。
  - 建議注入量：**初次加入 800 c.c.**，熱車怠速後量測油尺，若不足再微量補充至網格中上方。
  - **警示**：若一次灌滿 1,000 c.c.，容易造成油位過高，導致曲軸旋轉擊打機油產生氣泡、加速劣化，並讓引擎起步悶鈍、吹漏氣噴機油至空濾箱。

## 3. 機油尺標準量測方式
1. 車輛停於平地並立起主腳架。
2. 發動引擎 3 分鐘，熄火靜置 3~5 分鐘讓機油回流油底殼。
3. 旋出機油尺，以乾淨無塵紙巾拭淨。
4. **重點**：將油尺直立插入注油孔到底，**切勿旋入螺紋**。
5. 拔出檢視，油跡位於十字網狀刻度之中線偏上方即為最適狀態。
