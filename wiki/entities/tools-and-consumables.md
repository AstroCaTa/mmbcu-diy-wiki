# DIY 保養必備手工具與耗材實體說明

> 齊全適當的工具是 DIY 保養成功且避免損害愛車螺栓的第一要件。

## 1. 必備手工具（Tools）

| 工具名稱 | 規格尺寸 | 適用作業部位 | 備註與選購建議 |
| :--- | :--- | :--- | :--- |
| **六角套筒 / 梅花扳手** | 12mm | 左側底機油洩油螺栓 | 建議使用 6 角套筒，受力均勻不易傷螺栓角 |
| **六角套筒 / 棘輪扳手** | 17mm | 底部機油濾網螺帽蓋 | 短套筒或梅花扳手，注意施力垂直度 |
| **六角套筒 / T桿** | 10mm | 齒輪油注油與洩油螺栓 | 齒輪箱專用，T 桿手感清晰 |
| **二分微型扭力扳手** | 5 ~ 25 N-m | 機油螺栓 (12~15 N-m)、齒輪油螺栓 (10~14 N-m) | 新手必備，防滑牙救星 |
| **長頸細口漏斗** | 長度 20~25cm | 機油注油孔 | MMBCU 車身包覆較深，普通漏斗易卡車殼 |
| **量杯 / 刻度油壺** | 1000 c.c. 容量 | 機油精確量測 | 精準掌握 800~850 c.c. 注入量 |
| **扁平型廢油接油盆** | 容量 2~3 公升 | 車底接舊油 | 高度需低於車底底盤（建議高度 < 12cm） |

## 2. 耗材與配件（Consumables）

| 耗材名稱 | 規格型號 | 更換週期 | 功能說明 |
| :--- | :--- | :--- | :--- |
| **機油洩油墊片** | M12 鋁合金 / 紅銅華司 | 每次更換機油時換新 | 隨螺栓迫緊變形填補縫隙，防止滲油 |
| **齒輪油洩油墊片** | M8 鋁合金 / 紅銅華司 | 每次更換齒輪油時換新 | 齒輪箱防漏密封墊片 |
| **機油濾網 O-ring** | 原廠耐熱耐油橡膠圈 | 檢查彈性，約 10,000 km 換新 | 17mm 濾網螺帽油封，拆卸時塗微量新機油潤滑 |
| **煞車/零件清潔劑** | 氣壓噴霧式 | 每次作業使用 | 迅速揮發清潔螺栓、螺孔與周圍油漬 |
| **無塵擦拭紙 / 抹布** | 耐油型 | 每次作業使用 | 擦拭機油尺與滴漏油漬 |
| **丁腈耐油手套** | 拋棄式 | 每次作業使用 | 保護雙手避免長時間接觸廢機油化學物質 |
